# 07 – References and Glossary

## 1. Glossary

| Term | Meaning in ORVO |
|---|---|
| Opportunity | A hackathon, internship, job or freelancing listing curated on ORVO |
| Preparation resource | A tutorial, practice-question set, project guide or learning material |
| Category | A label used to classify opportunities or resources |
| Saved opportunity | An opportunity a student has bookmarked |
| Preparation progress | A student's status (not started, in progress, completed) on a resource |
| Administrator | Team-appointed user who manages content |
| MVP | Minimum Viable Product: the smallest version delivering the core value |
| Official link | The URL of the provider's own page for an opportunity |
| Draft / Published / Archived | Visibility states of an opportunity |
